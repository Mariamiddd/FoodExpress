🔍 TROUBLESHOOTING QUICK TIPS
==============================

Can't login?
  → Check email & password match EXACTLY (passwords are case-sensitive)

Can't find restaurants?
  → Wait 30 seconds after app startup (first run creates DB & seed data)

Got 404 error?
  → Make sure you're using the app at https://localhost:7280 (not http)
  → Check browser console (F12) for exact error

Admin button not showing?
  → You're not logged in as admin
  → Use: admin@gmail.com / Admin123!

API test file not working?
  → Install VS Code extension: "REST Client"
  → Or use test-api.sh script instead
